# nginx with TLS (self-signed dev) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar uma borda TLS com nginx (container) na frente do `identity_api`, servindo HTTPS na porta `443` com certificado self-signed e redirecionando `80 → 443`.

**Architecture:** Um serviço `nginx` (`nginx:alpine`) entra no `deploy/docker-compose.yml`, na mesma rede dos demais. O certificado self-signed é gerado no host por um script idempotente (`openssl`) para `deploy/certs/` (ignorado pelo git) e montado read-only no container. O `nginx` faz proxy reverso de `https://<host>/*` para `http://identity_api:8000` e responde `301` em HTTP. A porta `8000` continua publicada.

**Tech Stack:** Docker 28, Docker Compose v2, nginx 1.27-alpine, OpenSSL 3, Bash.

**Base branch:** `develop`.

**Branch de trabalho:** `issue32_nginx_tls` (criada na Task 0).

**Spec:** `docs/superpowers/specs/2026-09-26-nginx-tls-design.md`.

## Task 2: Script de geração do certificado self-signed

**Files:**
- Create: `deploy/scripts/gen-self-signed-cert.sh`

- [ ] **Step 1: Criar o diretório e o script**

Crie `deploy/scripts/gen-self-signed-cert.sh` com o conteúdo:

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
CERT_DIR="${TLS_CERT_DIR:-$SCRIPT_DIR/../certs}"
CERT_HOST="${TLS_CERT_HOST:-localhost}"
CERT_DAYS="${TLS_CERT_DAYS:-365}"

CERT_FILE="$CERT_DIR/fullchain.pem"
KEY_FILE="$CERT_DIR/privkey.pem"

if ! command -v openssl >/dev/null 2>&1; then
  echo "ERROR: openssl não encontrado. Instale o openssl e tente novamente." >&2
  exit 1
fi

if [ -f "$CERT_FILE" ] && [ -f "$KEY_FILE" ] && [ "${FORCE:-0}" != "1" ]; then
  echo "Certificado já existe em $CERT_DIR (use FORCE=1 para regenerar)."
  exit 0
fi

mkdir -p "$CERT_DIR"

if [[ "$CERT_HOST" =~ ^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
  SAN="DNS:localhost,IP:127.0.0.1,IP:$CERT_HOST"
else
  SAN="DNS:localhost,DNS:$CERT_HOST,IP:127.0.0.1"
fi

openssl req -x509 -nodes -newkey rsa:2048 \
  -keyout "$KEY_FILE" \
  -out "$CERT_FILE" \
  -days "$CERT_DAYS" \
  -subj "/C=BR/ST=SP/L=Sao Paulo/O=LINX/CN=$CERT_HOST" \
  -addext "subjectAltName=$SAN" \
  -addext "basicConstraints=critical,CA:FALSE" \
  -addext "keyUsage=critical,digitalSignature,keyEncipherment" \
  -addext "extendedKeyUsage=serverAuth"

chmod 600 "$KEY_FILE"

echo "Certificado self-signed gerado:"
echo "  cert: $CERT_FILE"
echo "  key:  $KEY_FILE"
```

## Task 3: Configuração do nginx

**Files:**
- Create: `deploy/nginx/nginx.conf`

- [ ] **Step 1: Criar o arquivo de configuração**

Crie `deploy/nginx/nginx.conf` com o conteúdo:

```nginx
server {
    listen 80;
    server_name _;

    server_tokens off;

    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    http2 on;
    server_name _;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;
    ssl_session_cache   shared:TLS:10m;
    ssl_session_timeout 10m;

    resolver 127.0.0.11 valid=10s ipv6=off;

    server_tokens off;

    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    location / {
        set $backend "identity_api:8000";
        proxy_pass http://$backend;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

> `identity_api` é o nome do serviço no Compose (rede interna); o proxy resolve
> pelo DNS embutido do Docker.

    image: nginx:1.27-alpine
    restart: unless-stopped
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro

    ports:
      - "80:80"
      - "443:443"

## Notas de execução (desvios do plano original)

Durante a revisão de qualidade e a verificação end-to-end, os itens abaixo foram
ajustados em relação aos snippets das Tasks 1–6. A spec
(`docs/superpowers/specs/2026-09-26-nginx-tls-design.md`) reflete o estado final.

1. **Healthcheck do nginx** (`deploy/docker-compose.yml`): URL alterada de
   `https://localhost/health` para `https://127.0.0.1/health` — dentro do
   container `localhost` resolve para `::1`, mas o nginx escuta IPv4; a versão
   original ficava permanentemente `unhealthy`. O `depends_on` do nginx passou a
   `condition: service_healthy`.
2. **Upstream dinâmico** (`deploy/nginx/nginx.conf`): adicionados
   `resolver 127.0.0.11 valid=10s ipv6=off;` e `proxy_pass http://$backend;`
   (variável) para não cachear o IP do `identity_api`. Adicionado `http2 on;`.
3. **SAN condicional** (`deploy/scripts/gen-self-signed-cert.sh`): se
   `TLS_CERT_HOST` for IPv4, gera `IP:$TLS_CERT_HOST`; senão `DNS:$TLS_CERT_HOST`.
4. **Caminho do runbook** (`docs/saas_backend/README.md`): removido o caminho
   absoluto `~/LINX-...`; usa `./scripts/gen-self-signed-cert.sh` após `cd deploy`.
5. **Backend `/health` com HEAD** (fora do plano; necessário para o critério
   `curl -I` = 200): `saas_backend/identity_api/src/identity_api/main.py` passou
   a `@app.api_route("/health", methods=["GET", "HEAD"])`, com o teste TDD
   `test_health_supports_head` em `tests/test_main.py`. Sem isso, `curl -I`
   retornava `405` (`allow: GET`).

**Resultado da Task 7 (local, portas 80/443):** HTTPS 443 → `HTTP/2 200`;
HTTP → `301 Location: https://localhost/health`; handshake TLSv1.3/ALPN `h2`
com cert self-signed; porta 8000 → `200`; healthcheck do `nginx` → `healthy`.

**Pendência de deploy:** liberar `80`/`443` no Security Group da EC2 (não
cobertas pela issue #31).
